Banco & Storage

Hot path = SQLite (NVMe). Espelho = Postgres no HD K:\STORAGE.

O que é o quê?

  • SQLite — onde a coleta grava a cada ~30s e o Dashboard lê. É o “quente”.
  • Postgres (K:) — cópia no HD do escritório. O flush copia do SQLite para cá de tempos em tempos.
  • DATABASE_URL — se trocássemos agora, a app passaria a usar só o Postgres. Ainda não fazemos isso: o HD USB pode oscilar; o SQLite no NVMe é mais seguro para coletar.
